Field View — Desktop

Static mockup, no functionality, 1440×820 laptop viewport, styled to the Light Film Room system like the phone/tablet mockup. Heat values are illustrative, not the real space model.

Principle: same top-bar idea and same field as the phone, but every “one tap away” item from mobile is now simply on screen — the mode switcher is tabs instead of a hamburger, the setup list / play list is an always-open right sidebar, and the Watch frames sit in a filmstrip. Nothing new is invented; things are unfolded. Build is a placeholder for now.
