Field View — Build

Static mockup, no functionality, in the Light Film Room style of the earlier mockups. It follows docs/fieldview-build-functional-spec.md: a play is a list of frames; each frame stores only the players you placed in it and everyone else inherits the previous frame; the disc holder inherits the same way; the mark is whoever is within 10 ft of the holder. The play shown is “Go deep”, five frames, editing frame 4. Heat values are illustrative.

What the field is telling you

1 · Build — desktop (editing frame 4 of 5)

Same bones as Explore

  • Field, setup-style sidebar, dock under the field — nothing relearned
  • Drag, marquee and arrow-key nudge behave exactly as in Explore

What Build adds

  • Top bar: undo / redo, “Saved to this device”, Share
  • Sidebar: My plays (the one saved list), play name and description
  • Under the field: Frame card, Selected-player card, Preview card, and the frame strip with + Add frame

Showing inheritance

  • Dashed ghost at the inherited spot + arrow for anyone placed in this frame
  • Small pink square on every piece placed in this frame; frame thumbnails show a count badge
  • Reset player / Reset frame put them back to inheriting

2 · Build — tablet / phone (secondary)

Build is laptop-first but usable on a tablet. Same top bar slots as Explore (☰ + mode, the chip — now a frame chip — legend); the sidebar's jobs become a frame strip under the field, a row of frame actions, and a slide-over for the selected player. Phone-sized screens would use the same pieces, one at a time.

Top bar

  • ☰ menu + BUILD · frame chip ◀ 4 / 5 ▶ · undo / redo · legend · Share

Under the field

  • Frame strip (four across, scrolls), then actions: Add · Duplicate · Delete · Reset frame · Preview

Selected player

  • A bar under the actions (not a slide-over: a panel over the field would hide the piece being edited): title, Give disc, Reset player

3 · Share

Link

  • The play is encoded in the link itself — nothing is uploaded, no account
  • A link is a snapshot: later edits don't change a link already sent

QR + file

  • QR for the huddle (point phones at the laptop)
  • File export / import as the backup path

4 · Explore — selected-player panel (desktop)

Explore gets the same selected-player card (the only difference is the extra panel under the field): naming and Give disc are useful there too, with no frames involved.

Panel

  • Title (≤ 2 characters, shown inside the piece), Give disc, quick facts
  • No frame controls, no “placed in this frame”

Same piece language

  • Green ring = holds the disc · heavy ring = the mark · pink ring = selected

Control → what it does to the document

ControlEffect on the play
Drag a playerPlaces them in this frame (their own position); later frames that inherit them follow
Reset playerRemoves that player's placement in this frame — they inherit again
Reset frameRemoves every placement and any “Give disc” in this frame — it equals the previous frame
Give discSets the disc holder for this frame (later frames inherit it); the new mark is whoever is within 10 ft
+ Add frame / DuplicateInserts an empty frame after the current one (identical to the previous)
Delete frameRemoves it and its changes; later frames now inherit from what is before them
TitleSets the player's title for the whole play (not per frame)
Undo / RedoSteps through completed gestures (drag, give disc, rename, add / delete / reset)
PreviewPlays the transitions exactly as Watch will show them
