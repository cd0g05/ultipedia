Field View — Watch & Explore (rev 3)

Static mockup, no functionality; colours, fonts and styling are placeholders — the point is layout. Phone frames are 844×390 (landscape, 1:1 CSS px); tablet is 1180×820. Heat values are illustrative (distance to nearest defender), not output of the real space model. Frames scale down to fit your window.

Rev 3 — styled to the Light Film Room system (style-guide/design.md): hard corners, zinc neutrals, pink #be185d for interactive/primary, green #047857 for on-states, Archivo Black headings, JetBrains Mono uppercase UI labels, Helvetica Neue body, graph-paper backdrop. Layout is unchanged from rev 2. Changes in rev 2: all chrome now lives in one top bar. The readout/caption is gone. Setup picker and colour guide moved to the top. “Defense follows” moved into the menu. Tablet no longer unfolds controls — it is the phone layout, larger. Default heatmap is back to red/amber/green, with a colour-blind mode in Settings.

1 · Explore (phone, landscape)

Always on screen (one top bar)

  • left ☰ menu + current mode
  • centre setup chip with ◀ ▶ to flip presets
  • right colour guide (legend, tappable) + reset

One tap away

  • chip setup list
  • legend “how to read the colours”
  • player highlight ring (detail TBD)
  • ☰ modes, Defense follows, Settings

Hidden

  • Settings colour-blind mode, layers, force, motion tunables, piece size

Everything below the bar is field. Note the field is width-limited on a 19.5:9 phone, so the real gain is breathing room; on squarer screens (iPad, older phones) it is a genuinely taller field.

2 · Watch (phone, landscape)

Always on screen (one top bar)

  • left ☰ menu + mode
  • centre ◀ prev · ▶ play/pause · next ▶, plus progress dots (2/4)
  • right colour guide + play selector

One tap away

  • dots jump to a frame
  • play chip play list
  • field pause / resume

Hidden

  • menu speed, loop, trails, show captions (when authored plays have them)

No caption for now. Captions return when coaches can author them — they would appear as an optional overlay, not permanent chrome.

3 · Menu open

  • Modes first. Build is listed but flagged as laptop-first.
  • Defense follows now lives here as a switch (Explore only).
  • Colour-blind mode is a switch under Settings; frame 5 shows its effect.
  • Field remains visible, dimmed, behind the drawer.

4 · Setup picker

  • For now: a handful of presets authored by you (names and one-line takeaways are placeholders).
  • Later: “Your setups” section for coach-made presets; the same panel doubles as Watch's play list.

5 · Colour-blind mode on

  • Same layout; only the heat ramp changes (orange → neutral → blue) and the legend follows it.
  • Pieces already avoid hue (filled = offense, ringed = defense), so only the heatmap needs a mode.

6 · Explore (tablet, landscape)

  • Identical to the phone layout, just scaled up (bigger targets, same slots).
  • The field is width-limited, so a 4:3 tablet leaves empty space below. Here it is centred; options are a larger piece size, a second row for info later, or leaving it calm.
